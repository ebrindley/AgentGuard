Agent Guard List

Put one folder or file per line under a heading. Drag it in from Finder or type a
path starting with / or ~. Delete a line to remove it. Lines starting with # are
ignored. Save, then quit and reopen OpenCode.

By default, OpenCode can read and search files your macOS account permits,
including folders not listed here, except credential folders such as the .ssh,
.aws and .gnupg folders in your home and .env files, which are blocked without
being listed. An empty READ ONLY section does not restrict reading.

ALLOW grants permission to create, change, and delete files. READ ONLY removes
write permission, for example from a subfolder inside an ALLOW folder. DENY
blocks both reading and writing. When entries overlap, DENY always wins;
otherwise the most specific entry wins.

OpenCode's ordinary global configuration, standard skills, required data, cache,
and temporary folders remain writable automatically. Guard-owned entries and
automatic root identities remain protected. See last-launch-opencode.log next to this file for the applied locations.
Build tools with their own folders in your home, such as ~/.cargo or ~/go, need
those folders under ALLOW.
