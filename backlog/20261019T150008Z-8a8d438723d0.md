# Support OpenCode 1 and 2

## Description

## Scope / Surfaces Affected
Port the OpenCode plugin, launchers, readiness checks and permission diagnostics to OpenCode 2 while retaining OpenCode 1 behavior. Update packaging, relevant documentation and existing test coverage.

## Acceptance Criteria
Both versions load the Guard plugin and preserve Guard List enforcement. V2 tool execution occurs in the guarded server. Diagnostics identify the selected runtime and report unsupported or degraded states without claiming protection. Existing V1 behavior remains supported.

## How to Verify
Run focused adapter, launcher and diagnostics tests with Node 24. Exercise pinned V1 and V2 runtimes in disposable homes. Run the required hosted gate before landing; full validation owns release qualification.
