# Fix intermittent browser test failure

## Description

## Scope / Surfaces Affected

`test/browser.mjs`, which the hosted `tests` gate runs, intermittently fails with
`connect ECONNREFUSED` on the browser helper's socket under a temporary
`agentguard-browser-test.*` folder. It failed on the first gate run of #232 and
of #239 and passed on rerun of the same commit both times. Neither change
touches the browser helper or its test.

Find whether the test connects before the helper listens or the helper is slow
to start or exits on the hosted runner, and correct that cause in the test or in
`profiles/opencode/browser/helper.zsh`.

## Acceptance Criteria

- [ ] The cause of the refused connection is identified from the test and helper source or a reproduction.
- [ ] The test waits on the helper's readiness, or the helper defect is fixed; no blanket retry is added around the whole file.
- [ ] No profile rule or helper URL policy changes.

## How to Verify

- The hosted `tests` check on the pull request.
