# Replace the app's template privacy text

## Description

Agent Guard.app is an osacompile applet, and macOS treats it as the responsible process for OpenCode's privacy requests. Its Info.plist keeps osacompile's template strings. On 2026-10-24, OpenCode's microphone request appeared as "'Agent Guard' would like to access the Microphone. This script needs access to your microphone to run." The rebuild check (`ag_app_decide`) hashes only the script, the bundle ID and the icon, so a change to the plist alone would never reach installed apps.

## Scope / Surfaces Affected

- `installer/lib.zsh`: `ag_build` and `ag_app_decide`.
- The test that covers the app build (`test/install.sh` or equivalent).
- `docs/OPERATIONS.md` or `docs/USAGE.md`, if they describe the app's metadata.
- Out of scope:
  - adding or removing keys;
  - the signing identity;
  - responsibility disclaim;
  - the launcher.

## Acceptance Criteria

- Each of the 11 `NS*UsageDescription` keys that osacompile writes says that OpenCode, running inside Agent Guard, asked for the access and that Agent Guard does not use it itself.
- The strings are part of the rebuild inputs, so the next update rebuilds an installed app once.
- The app's signature verifies after the change.

## How to Verify

- The build test reads the built Info.plist and checks every usage key.
- A second install with unchanged inputs does not rebuild the app.
- The hosted `tests` check passes.
