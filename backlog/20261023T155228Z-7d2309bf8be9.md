# Document the Claude background-session peer limit

## Description

Claude Code runs background sessions (`--bg`, agent view) under a supervisor that may already be running outside Agent Guard. Record in SECURITY.md what a guarded Claude peer can do with it in Claude Code 2.1.309, and the condition under which that changes.

## Scope / Surfaces Affected

- `SECURITY.md`, Peer CLI execution.

## Acceptance Criteria

- States that peer wrappers do not mediate IPC with processes started outside the session.
- States the 2.1.309 behavior: the client creates the job folder under its configuration folder before dispatch, and a guarded `claude --bg` fails with EPERM when that folder is outside the write grants, as `~/.claude/jobs` is.
- Names the flag-gated storage path that would remove this barrier, and states that direct dispatch to the supervisor's control socket is not established either way.

## How to Verify

- Documentation only.
