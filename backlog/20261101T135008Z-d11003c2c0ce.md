## Description

## Scope / Surfaces Affected

Make the existing integration fixture independent of inherited XDG roots, include installer output in installed-state assertion failures, provide ripgrep in the existing Full validation setup, and clarify checkout placement for affected suites. Changes are limited to test/test.sh, test/install-state.mjs, .github/workflows/full.yml and docs/DEVELOPMENT.md. The Pi fixture credentials fragment is already included by PR #183.

## Acceptance Criteria

- The integration fixture leaves externally supplied XDG config/data/state folders untouched.
- Installer and uninstaller status assertion failures include the child command output.
