# Turn off OpenCode's shared service at install

## Description

## Scope / Surfaces Affected

- `installer/harness/opencode.zsh`: a journaled switch action that writes `disabled: true` into OpenCode 2's service config (`~/.config/opencode/service.json`) once per Mac, recorded in the permission record, with undo and uninstall restore through the existing record and restore functions.
- `installer/actions.zsh`: the action registry row.
- `test/opencode-config.mjs`: the action's cases; `test/install.sh`: test point coverage list.
- `docs/USAGE.md`, `docs/OPERATIONS.md`, `docs/DESIGN.md` (section 6 and decision D11), `SECURITY.md`.

## Acceptance Criteria

- With no record entry for the service config: an absent key is written as `true` and recorded `{orig: null, wrote: true}`; `true` or `false` is left and recorded `{orig}` with no `wrote`.
- A missing file is created as `{"disabled": true}` with mode 0600 (OpenCode fills in `password` on demand).
- An existing entry means the file is never touched again, even when the key was removed.
- An unreadable or invalid file is left unchanged, warned about and not recorded.
- The write keeps every other key and the file mode, never runs `opencode service set`, and never prints the file's contents.
- An interrupted run resumes or rolls back; uninstall restores only while the value equals the recorded `wrote`.
- One installer output line.

## How to Verify

- `node test/opencode-config.mjs` covers each case with disposable homes and a fake password.
