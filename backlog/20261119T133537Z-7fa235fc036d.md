# Keep Grok and Pi launches guarded after updates

## Description

## Scope / Surfaces Affected
Grok and Pi/Oh My Pi installation diagnostics for vendor-replaced launchers. Verify the Pi collision with an isolated npm install before deciding whether to move the entry points into the Guard release.

## Acceptance Criteria
- Grok doctor reports drift at the installed launcher link even when the interactive shell still resolves to Agent Guard. Correct the update guidance.
- Pi and Oh My Pi doctor report Guard resolution only after verifying the launcher reached by the command.
- If a supported npm update reproduces the collision, give the ordinary Pi and Oh My Pi commands independent Guard entry points and preserve safe restart and wrapper behavior.

## How to Verify
Run the focused installation fixtures for launcher replacement. Perform the npm experiment with a disposable prefix and the genuine published Pi package.
