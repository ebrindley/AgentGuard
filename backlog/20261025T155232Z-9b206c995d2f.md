# Correct desktop update and sign-in guidance

## Description

docs/USAGE.md, "OpenCode Desktop behavior", is out of date or incomplete in three places:

- The update bullet says Homebrew upgrades the `auto_updates` cask only when it is named on the command line. Homebrew 7.0.10's `brew upgrade` also upgrades it once the installed app is older than the tap's version (`Cask#outdated_version` in `cask/cask.rb`; default `HOMEBREW_UPGRADE_AUTO_UPDATES_CASKS`, turned off by `HOMEBREW_NO_UPGRADE_AUTO_UPDATES_CASKS`). The bullet also predates 2026.10.25, which denies the authorization service to the desktop, so the update now fails without an administrator prompt.
- The links bullet omits that right-clicking an ordinary link offers Copy Link. OpenCode Desktop 2.1.4 enables `electron-context-menu` with `{showSaveImageAs: true, showLookUpSelection: false, showSearchWithGoogle: false}`, which leaves `showCopyLink` on (read from `app.asar`, not tried in the app).
- The sign-in guidance does not say that `opencode auth login` works in a guarded terminal: the launcher runs `auth` with `--standalone` (`profiles/opencode/runtime.zsh`), and the 2.1.4 CLI prints the sign-in URL before it tries to open the page.

## Scope / Surfaces Affected

- docs/USAGE.md, the update and links bullets of "OpenCode Desktop behavior".
- Out of scope: the microphone bullet, other docs, code.

## Acceptance Criteria

- The update bullet states that plain `brew upgrade` upgrades OpenCode Desktop once the installed app is older than Homebrew's version, names the setting that turns this off, keeps `brew upgrade --cask opencode-desktop`, and states that the in-app update fails without a prompt.
- The links bullet names right-click Copy Link for ordinary links, marked as read from the bundle.
- The sign-in text says `opencode auth login` can run in a guarded terminal and prints the URL. That the desktop then uses the saved credential stays marked as an inference.

## How to Verify

- Read the changed bullets against the sources named above.
- The hosted `tests` check passes.
